# 账号限制：官方边界与可诊断范围

## 官方规则

[Antigravity Additional Terms](https://antigravity.google/terms) 第 6 节禁止“使用第三方软件、工具或服务访问该服务”（条款举例为 OpenClaw 配合 Antigravity OAuth），并写明此类行为可能导致 Antigravity 和/或 Gemini CLI 账号被暂停或终止。

[Antigravity FAQ](https://antigravity.google/docs/faq/) 当前进一步说明：

- agy -p 面向直接脚本和 CI 工作流。
- 消费计划不支持将 agy 包装在第三方 coding agent 或应用中，也不支持自动轮换账号。
- 若要在第三方 coding agent 中使用 Gemini，Google 建议使用 Gemini Enterprise 或 Google AI Studio API key。

按 FAQ 核对最低年龄、支持地区和账号资格。资格问题应走官方页面，不要尝试通过代理、账号切换、改设备标识或伪造地区解决。

## 状态码不能单独解释账号状态

| 信号 | 可以得出的结论 | 不能据此得出的结论 |
|---|---|---|
| 429 / RESOURCE_EXHAUSTED | 发生了请求频率、用量、消费上限或容量问题；需看具体产品、project/model 和返回信息。 | 不能单凭 429 认定封号，也不能用换账号/新 project 绕过限制。 |
| 一般 403 / PERMISSION_DENIED | 当前请求未获准。检查登录/权限、地区资格、API key、project、计费、端点及服务状态。 | 不能单凭 403 认定永久封号或条款处罚。 |
| 明确 service disabled 并附 ToS 违规提示 | 这是服务级限制的强信号；停止对被拒服务继续请求，并保留脱敏证据。 | 不代表 Gmail 或 Google 其他服务状态，不证明其他账号状态，也不提供恢复期限。 |
| TLS/DNS/连接超时/HTTP 404 | 对应网络探测的结果。HTTP 404 通常只说明端点返回了响应。 | 不证明已认证、模型调用成功、账号安全或地理资格满足。 |

Google 没有公开面向用户的处罚评分、设备/IP 关联机制、频率阈值、统一申诉时限或自动解封保证。不要把社区逆向猜测转化为规避方案或“防封参数”。

## 网络出口和客户端改造

正常系统代理可能只是网络传输配置；它是否符合用户所在地区、服务条款和网络政策，须分别判断。出口稳定、住宅 IP、hosting=false、proxy=false 或第三方数据库标签都不是官方账号安全证明，也无法把不支持的地区变成受支持地区。

DLL 注入、改写客户端文件、拦截请求或修改认证属于非默认客户端改造，可能带来安全、更新和条款适用问题。官方资料没有确认哪一种纯网络改造一定违规或一定允许；因此不把它作为账号风险控制，也不建议为账号风控目的部署。

## 发现服务限制时

1. 停止对被拒服务的重复请求、自动重试和自动切号。
2. 保存产品名称、客户端版本、时间、完整错误含义、request/trace ID；对邮箱、token、project ID 等脱敏。
3. 按当前产品 FAQ 的支持入口反馈，附最小复现和必要证据。不要依赖旧邮件地址、社区代申诉或未验证的“二次认证/二振”流程。
4. 后续仅按官方回复、资格页面或额度页给出的步骤恢复。没有官方恢复结论前，不宣称问题已解除。
