# 日常使用与风险控制（WorkBuddy / CodeBuddy）

> 本页只提供可验证、可逆的日常操作。它不能预测封号或保证账号不受服务端限制。

## 日常控制

1. 使用当前官方客户端、本人有权使用的账号、受支持的产品入口与地区；按当前产品界面查看计划、用量和服务提示。
2. 尊重产品使用限制，避免不必要的高频或并发请求；把大任务拆成可检查的小步。这样能控制请求量，不能保证账号安全。
3. 不提取、分享或代理订阅认证凭据，不使用来路不明的账号或积分，不伪造设备/请求信息，不以多账号轮换规避限制。第三方模型接入须使用该产品明确支持的独立 API 或企业入口，并遵守其条款。
4. 保存最少量的脱敏诊断信息：事件时间、产品版本、错误码、Trace/Request ID、界面显示的模型与计划，以及官方额度提示。不要分享 token、cookie、邮箱、device-id 或完整会话内容。
5. 输出质量发生变化时，先确认界面实际选择的模型、计划与上下文；如需比较，只做一次低成本、同输入、同模型的短对照。没有服务端证据时，不归因为“静默降智”。

## 遇到限制或拒绝

- **明确服务停用、条款或账号限制提示**：停止该入口的请求，保留脱敏错误和 Trace ID，通过当前官方客户端反馈/支持入口处理；不承诺恢复时间。
- **429 或界面限额提示**：遵守响应中的 Retry-After/reset 或客户端显示的恢复提示；不要循环提交、自动重放任务或切号绕过。没有明确恢复信息时，查当前官方用量与支持渠道。
- **6003 / 6004**：官方错误码页将其描述为请求频率受限，并建议优先切换模型重试。仅在当前官方客户端仍给出该建议时，由用户手动切换模型并重试一次；问题持续时停止重复尝试并反馈错误信息。不要把这一建议扩展成自动循环或规避账号/计划限制。
- **3002 / 3003 / 3007**：官方错误码页将其描述为多与网络环境有关；按官方网络排查指引或联系组织 IT。网络连通性成功不等于账号认证、模型调用或账号状态通过。
- **11140 / 403 request illegal**：截至本页引用的公开错误码列表未给出明确解释。先停止重复请求并记录脱敏 Trace ID；单条错误、普通问候失败或错误包装文本都不足以断定账号封禁、内容违规或 IP 封禁。

## 不作为风控判据

社区帖子、IP 分类数据库、固定出口、切换热点/账号的对照结果、客户端启动次数、单条日志、会话标题或错误中的 UUID，都不能单独证明账号处罚原因或恢复时间。不要为验证这些猜测而换号、改变设备指纹、反复切换网络、重启客户端或清除凭据。
