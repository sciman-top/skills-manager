# 网络错误与代理排查

> 仅用于区分公开错误码所指向的网络问题与账号/认证问题，不提供账号风险规避手段。

## 官方错误码提示

[WorkBuddy 官方错误码说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Error-Code) 当前描述：

| 错误码 | 官方说明 | 建议边界 |
|---|---|---|
| 3002 / 3003 / 3007 | 多与网络环境有关 | 按官方页面检查当前公司/家庭网络；页面建议参照“网络代理”关闭代理。遵守组织网络策略，需要时联系 IT。 |
| 6003 / 6004 | 请求频率受限，专业版也可能出现 | 官方建议优先切换模型重试。仅在当前官方客户端仍提示时，由用户手动切换模型并重试一次；不要自动循环或把它扩展为账号/计划限制的规避方法。 |
| 11133 / 11134 / 14003 | 多与模型侧状态有关 | 按官方说明新开会话或切换模型。 |

## 安全排查顺序

1. 记录出现时间、错误码、Trace/Request ID、客户端版本和界面提示；分享前删除账号标识、cookie、token、device-id 与会话内容。
2. 对网络错误，依官方客户端的网络诊断或组织 IT 指引排查当前连接。不要为账号风险反复切换出口、热点或代理。
3. 将普通网络可达性与认证、配额和实际模型请求分开记录。通用网站访问或 IP 查询只说明该项网络检查当时可达，不能证明 WorkBuddy 登录成功、业务端点可用或账号状态正常。
4. 对未被公开错误码说明覆盖的 11140 / 403 request illegal，不根据代理设置、IP 数据库标签或一次网络对照推断账号处罚原因；暂停重复请求并走官方反馈渠道。

不要用进程注入、客户端改造、请求拦截、订阅凭据网关或多账号轮换来测试、隐藏或绕过服务端限制。
