# Bounded Research

Start with repository truth, then use official documentation, first-party
source, specifications, or APIs only as far as needed to make the current
decision reversible and evidence-backed. Stop when additional reading would not
change the decision.

Research is read-only by default. Do not create a Markdown report, evidence
file, issue, task, or external record unless the user explicitly asks to persist
the findings.

Use a background agent only when a genuinely independent, bounded research
question can run in parallel with useful local work. Otherwise research inline.
Delegation does not broaden authority, write scope, or acceptance claims.

Return the decision, decisive evidence, uncertainty, and any freshness boundary
in the current response. Do not turn a small lookup into a survey of the field.
