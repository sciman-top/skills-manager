# Reference shelf

Optional read-only development cache; not runtime state and not a prerequisite for build, test, update, or projection. `skills.json` remains the runtime source of truth.

Boundary, tiers, manifest, and refresh/verify commands are defined in [`docs/EXTERNAL_REFERENCE_REPO_TIERS.md`](../docs/EXTERNAL_REFERENCE_REPO_TIERS.md). Refresh receipts go to ignored `reports/reference-refresh/<run-id>/receipt.md`.
